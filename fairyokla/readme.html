介紹頁 · 開發記事

這份文件記錄「科技仙姑實驗室／仙姑行不行」頻道介紹頁的做法：檔案結構、設計決策、 版面評審過程、部署流程，以及目前已知的限制。頁面本身是純靜態單檔，沒有任何建置工具或相依套件。

靜態 HTML 無相依套件 GitHub Pages 最後更新 2026-08-17
01

專案概要

單頁介紹網站，內容取自 YouTube 頻道「科技仙姑實驗室」的公開簡介：節目宗旨、兩位主持人 （科技仙姑 Alice、麻瓜女 SuSu）、頻道基本資料。

技術上刻意維持零建置：所有 CSS 內嵌於 <style>， 僅有一段約 10 行的 JavaScript 負責捲動時的吸附列縮放。沒有框架、沒有外部字型或 CDN， 整份頁面離線也能完整呈現，唯一的外部資產是頻道橫幅圖。

字型策略

未載入網路字型，改用系統字型堆疊：中文標題優先 Noto Serif TC／思源宋體（宋體帶靈性、經文感）， 內文用 Noto Sans TC／PingFang TC，拉丁文與標籤一律等寬字（科技感）。 宋體與等寬字的並置，就是「通靈 × 科技」這個主題的字型對應。

03

設計決策

深色主題

底色 #07080d，靈光青 #56e0c0、朱砂 #e2573f、 燙金 #d9a441 三個重點色。背景疊了三層 radial-gradient 氣場光暈與一層 SVG 雜訊顆粒（feTurbulence，overlay 混合），避免大面積純色的廉價感。

吸附式橫幅

position: sticky 搭配毛玻璃底，捲動超過 24px 後加上 .stuck： 內距縮小、標誌字級縮小、底色加深並帶陰影。捲動事件以 requestAnimationFrame 節流，並加 {passive:true}。

橫幅圖的融合處理

頻道橫幅是暖金＋近白的淺色調，與深色頁面直接相接會出現硬邊。處理方式是用 mask-image 雙層遮罩（左右各 14%、底部 38% 淡出）讓圖片四邊溶進背景， 再加 brightness(.94) 與上緣壓暗漸層。 YouTube 橫幅左側原本為裝置安全區留的大片空白，也因此自然淡化。

無障礙與偏好設定

  • prefers-reduced-motion 下關閉所有進場動畫
  • 導覽錨點加 scroll-margin-top，避免標題被吸附列遮住
  • 頻道信箱未公開，頁面標示取得方式而非填入臆測的地址
04

版面評審紀錄

橫幅圖導入後做過一次評審，當時同一張圖同時出現在吸附列與頁首滿版區。以下是問題與處置：

等級問題處置
P0 同一張圖上下相鄰出現兩次，且吸附列版本是滿版版本的劣化裁切 吸附列改為燙金漸層文字標誌，僅頁首保留圖片
P0 白底橫幅與深色頁面之間的漸層像壓圖失敗，左右邊界生硬 改用 mask-image 四邊羽化＋亮度微調
P1 吸附列標誌字高不足 10px，實質不可讀 改文字標誌，字級 20px，捲動後 17px
P1 ALICE & SUSU 白字壓在近白背景，對比遠低於 4.5:1 移除（主持人已於「兩個聲音」段落完整介紹）
P2 橫幅過高、視覺重心壓過頁面主標 高度上限收到 clamp(110px,18vw,230px)
05

部署

走 GitHub Pages，發佈在個人站台 mango-pool.github.io 的 /fairyokla/ 子路徑下。本機的 E:\修正行識\仙姑行不行 是工作目錄， E:\AI 學習計劃\hello-pages 是站台的 Git 儲存庫。

更新流程

改完本機檔案後，把整個資料夾同步到儲存庫並推送：

robocopy "E:\修正行識\仙姑行不行" "E:\AI 學習計劃\hello-pages\fairyokla" /MIR
cd "E:\AI 學習計劃\hello-pages"
git add fairyokla
git commit -m "Update fairyokla page"
git push

推送後 GitHub Pages 約 1 分鐘完成建置。頁面網址： mango-pool.github.io/fairyokla/

06

已知限制與待辦

  • mask-composite 相容性：Safari 15.4 以前不支援，橫幅會退回無羽化的硬邊。 不破版，但融合效果消失。
  • 圖片授權：橫幅圖是頻道的官方視覺素材。公開發佈前應確認已取得頻道方同意， 或改用自製視覺。頁面文案同樣取自頻道公開簡介。
  • 頻道信箱：YouTube 僅提供「查看電子郵件地址」按鈕，未公開實際地址， 頁面標示為未公開。
  • 未做：Open Graph／社群分享預覽圖、favicon、節目單集列表。
