Q：uv 是裝在專案資料夾，還是 C 槽（OS 系統層）？

A：uv 本體裝在系統（使用者目錄），但它管的環境在各專案裡。三層分開看：

東西位置裝幾次
uv 工具本體C:\Users\你\.local\bin\uv.exe（使用者目錄，非專案）一次，全機共用
Python 直譯器C:\Users\你\AppData\Local\uv\（中央倉庫）每個版本一次，所有專案共用
各專案套件環境專案資料夾\.venv\（跟著專案走）每個專案自己一個

重點：

  • .venv 裡的套件是從中央快取連結過來的，十個專案用同一套件，磁碟只存一份——這是 uv 快又省空間的原因之一
  • 刪掉專案資料夾 = 環境跟著乾淨消失，不留垃圾在系統裡（傳統 pip 全域安裝的老毛病）
  • 類比：uv 本體 ≈ node/npm 裝一次；.venv ≈ 各專案的 node_modules；中央快取 ≈ pnpm 的全域 store
